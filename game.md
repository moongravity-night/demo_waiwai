Этот документ описывает правила игры в анти-тетрис.

# Anti-Tetris — правила игры

## 1. Общая концепция

**Anti-Tetris** — игра с обратной механикой классического Tetris.

В начале уровня игрок получает уже собранный стакан из тетрис-фигур. Задача игрока — **полностью разобрать стакан**, последовательно удаляя доступные фигуры.

При клике на доступную фигуру она **улетает вертикально вверх** и удаляется со стакана.

---

## 2. Игровое поле

Игровой стакан имеет стандартный размер:

* **ширина:** 10 клеток;
* **высота:** 20 клеток.

Каждая фигура занимает несколько клеток игрового поля.

Фигуры не перемещаются и не вращаются пользователем после начала уровня. Игрок может только выбирать фигуры для удаления.

---

## 3. Фигуры

Используются стандартные тетрисовские фигуры — **тетромино**, каждая из которых состоит из четырёх клеток.

Доступны следующие типы фигур:

| Фигура | Базовая форма |
| ------ | ------------- |
| **I**  | `████`        |
| **O**  | квадрат `2×2` |
| **T**  | Т-образная    |
| **J**  | J-образная    |
| **L**  | L-образная    |
| **S**  | S-образная    |
| **Z**  | Z-образная    |

В стакане фигуры могут находиться:

* в различных допустимых поворотах;
* в зеркально отражённых состояниях;
* в различных позициях относительно игрового поля.

Таким образом, одна и та же базовая фигура может иметь несколько вариантов ориентации.

---

## 4. Основная механика разбора

Игрок кликает на фигуру, которую хочет удалить.

Фигура может улететь вверх **только в том случае, если её движение вверх ничем не заблокировано**.

### Условие доступности фигуры

Для **каждой клетки выбранной фигуры** необходимо проверить все клетки игрового поля, расположенные выше неё в той же колонке.

Если над любой клеткой выбранной фигуры находится клетка **другой фигуры**, выбранная фигура считается заблокированной.

Иными словами:

> Фигура может быть удалена, если от каждой её клетки до верхней границы стакана существует свободный вертикальный путь.

При этом клетки самой выбранной фигуры не считаются препятствием друг для друга.

### Успешный клик

Если фигура не заблокирована:

1. запускается анимация её движения вверх;
2. фигура покидает границы стакана;
3. фигура удаляется с игрового поля;
4. остальные фигуры остаются на своих местах;
5. игрок может выбрать следующую фигуру.

Фигуры **не падают вниз** после удаления других фигур.

---

## 5. Заблокированные фигуры

Если игрок кликает на фигуру, над которой находится хотя бы одна клетка другой фигуры, удалить её нельзя.

Такой клик считается ошибочным.

За ошибочный клик игрок получает **штраф**, определённый правилами текущего уровня.

Штраф может, например, уменьшать оставшееся время на прохождение уровня.

Конкретный размер и тип штрафа задаются параметрами уровня.

---

## 6. Цель уровня

Уровень считается пройденным, когда игрок удалил **все фигуры из стакана** до истечения установленного времени.

Если таймер достигает нуля до полного разбора стакана, уровень считается не пройденным.

---

## 7. Таймер

Каждый уровень имеет собственное ограничение по времени.

Продолжительность таймера является параметром уровня.

Таймер запускается при начале уровня и останавливается после удаления последней фигуры.

Ошибочные действия игрока могут дополнительно уменьшать оставшееся время в соответствии с настройками уровня.

---

## 8. Уровни

Игра состоит из последовательности уровней.

Изначально пользователю доступны только стартовые уровни.

Следующие уровни открываются **по мере прохождения предыдущих уровней**.

Таким образом, прогресс пользователя определяет набор доступных ему уровней.

Каждый уровень имеет собственный набор правил и параметров сложности.

---

## 9. Параметры уровня

Для каждого уровня может задаваться отдельная конфигурация.

В неё могут входить:

* время на прохождение;
* штраф за ошибочный клик;
* набор разрешённых типов фигур;
* процентное соотношение типов фигур;
* количество фигур;
* степень заполнения стакана по высоте;
* допустимые варианты поворота фигур;
* допустимые варианты отражения фигур.

Например, один уровень может состоять преимущественно из `I`, `O` и `T`, а следующий использовать все семь типов фигур.

---

## 10. Процедурная генерация стакана

Начальное состояние стакана формируется **процедурно** на основе конфигурации текущего уровня.

Генератор должен учитывать:

### Типы фигур

Уровень определяет, какие фигуры могут участвовать в генерации.

Например:

`I, O, T`

или:

`I, O, T, J, L, S, Z`

### Соотношение фигур

Для каждого типа может быть задана относительная вероятность или процент его появления.

Например:

| Фигура | Доля |
| ------ | ---: |
| I      |  10% |
| O      |  20% |
| T      |  30% |
| J      |  10% |
| L      |  10% |
| S      |  10% |
| Z      |  10% |

### Высота заполнения

Правила уровня определяют, насколько высоко может быть заполнен стакан.

Например:

* до 25% высоты;
* до 50%;
* до 75%;
* практически весь стакан.

Для стакана высотой 20 клеток это позволяет постепенно увеличивать количество и сложность расположения фигур.

### Ориентация

При генерации фигуры могут случайным образом:

* поворачиваться;
* зеркально отражаться;
* размещаться в допустимых позициях стакана.

При размещении фигуры не должны выходить за границы игрового поля или пересекаться с уже размещёнными фигурами.

---

## 11. Разрешимость уровня

Процедурно созданный стакан должен иметь возможность полного разбора.

То есть в любой момент до завершения уровня должна существовать последовательность допустимых действий, позволяющая удалить все фигуры.

Генератор не должен создавать состояния, в которых оставшиеся фигуры невозможно удалить независимо от действий игрока.

---

## 12. Рост сложности

Сложность уровней может увеличиваться за счёт комбинации параметров:

* большего количества фигур;
* большей высоты заполнения стакана;
* использования большего количества типов фигур;
* более сложных взаимных перекрытий фигур;
* уменьшения времени на прохождение;
* увеличения штрафа за ошибочные клики;
* изменения процентного состава фигур.

Основной навык игрока — визуально анализировать структуру стакана и определять правильный порядок удаления фигур.
