# Anti-Tetris — User Level Design

## 1. Общие принципы

Пользовательские уровни формируют последовательную кривую сложности Anti-Tetris.

Сложность увеличивается за счёт трёх основных параметров:

* количества типов фигур;
* степени заполнения стакана;
* времени, доступного на прохождение.

Новые уровни открываются последовательно после прохождения предыдущих.

```text
Level 1
  ↓
Level 2
  ↓
Level 3
  ↓
Level 4
  ↓
Level 5
  ↓
Level 6
```

Размер игрового стакана для всех уровней:

```text
Width:  10 cells
Height: 20 cells
Total:  200 cells
```

Все уровни должны генерироваться таким образом, чтобы существовала корректная последовательность удаления всех фигур.

---

# 2. Общие правила генерации

Для каждого уровня задаются:

```ts
interface LevelRules {
  id: number;
  fill: number;
  timeLimit: number;
  tetrominoTypes: TetrominoType[];
}
```

Если отдельно не указано иное, все разрешённые на уровне типы фигур используются с одинаковым весом.

Например:

```text
O + I

O: 50%
I: 50%
```

или:

```text
O + I + L + J

O: 25%
I: 25%
L: 25%
J: 25%
```

Для всех семи фигур:

```text
I
J
L
O
S
T
Z
```

используется одинаковый вес генерации.

Фактическое количество фигур конкретного типа может незначительно отличаться из-за общего количества фигур на уровне.

# 3. Level 1 — Обучающий

## Назначение

Первый уровень знакомит пользователя с базовой механикой Anti-Tetris:

* выбором фигуры;
* определением свободной фигуры;
* удалением фигуры;
* последовательным разбором стакана.

Используются только две наиболее простые визуально фигуры:

```text
O — квадрат
I — палка
```

Это позволяет пользователю освоить механику без необходимости сразу распознавать все типы тетримино.

## Параметры

| Параметр               |    Значение |
| ---------------------- | ----------: |
| Заполнение             |        ≈25% |
| Фактическое заполнение |         24% |
| Занятых клеток         |          48 |
| Количество фигур       |          12 |
| Фигуры                 |      `O, I` |
| Распределение          | равномерное |
| Время                  |   20 секунд |

### Конфигурация

```ts
{
  id: 1,
  type: "tutorial",

  fill: 0.24,

  timeLimit: 20,

  tetrominoTypes: [
    "O",
    "I",
  ],

  tetrominoWeights: {
    O: 1,
    I: 1,
  },
}
```

> Ровно 25% стакана соответствует 50 клеткам. Поскольку одна фигура всегда занимает 4 клетки, используется ближайшее возможное заполнение без превышения целевого значения: 48 клеток, то есть 24%.

# 10. Кривая сложности

Последовательность уровней построена таким образом, чтобы за один шаг преимущественно изменялся один основной параметр сложности.

```text
Level 1
O + I
≈25%
20 sec

   ↓ больше фигур

Level 2
O + I
50%
20 sec

   ↓ новые формы

Level 3
O + I + L + J
50%
20 sec

   ↓ полный набор фигур

Level 4
All
50%
20 sec

   ↓ полный стакан

Level 5
All
100%
20 sec

   ↓ меньше времени

Level 6
All
100%
15 sec
```

Таким образом пользователь последовательно осваивает:

1. базовую механику;
2. работу с более плотным стаканом;
3. сложные формы фигур;
4. полный набор тетримино;
5. большое количество фигур;
6. прохождение в условиях ограниченного времени.

---

# 11. Требования к генерации

Для каждого пользовательского уровня должны выполняться следующие условия:

1. Все фигуры находятся внутри границ стакана.
2. Фигуры не пересекаются.
3. Каждая фигура состоит ровно из четырёх клеток.
4. Используются только типы фигур, разрешённые правилами уровня.
5. Разрешённые типы фигур генерируются с одинаковым весом.
6. В начальном состоянии существует хотя бы одна фигура, которую можно удалить.
7. Уровень полностью разбираем согласно правилам Anti-Tetris.
8. Генератор должен проверить разбираемость уровня до его показа пользователю.
9. Если сгенерированная конфигурация неразбираема, она должна быть отброшена и создана заново.
10. Уровень считается завершённым только после удаления всех фигур до истечения установленного времени.
