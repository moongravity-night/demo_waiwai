# Anti-Tetris — выбранные звуки

Набор подобран под принципы `soft / tactile / ASMR-like / physical / satisfying` из `visual.md`.

## 01_piece_removal_layers

Три файла воспроизводятся вместе при успешном удалении фигуры:

1. `layer_1_soft_click.wav` — сухой короткий щелчок, запускается сразу.
2. `layer_2_wood_release.wav` — тактильный деревянный отклик, запускается вместе со щелчком или через 10–20 мс.
3. `layer_3_airy_whoosh.wav` — воздушный уход фигуры вверх, запускается через 30–60 мс.

Whoosh должен быть самым тихим слоем. Для разнообразия слегка меняйте громкость и высоту первых двух слоёв на каждом ходе.

## 02_feedback

- `blocked_muted_knock.wav` — клик по заблокированной фигуре. Использовать тихо, без дополнительных резких сигналов.

## 03_level

- `level_complete_kalimba_up.wav` — короткий органический восходящий знак победы.
- `time_out_arp_down.wav` — мягкий нисходящий знак окончания времени.

## 04_ui

- `button_soft_percussion.wav` — нейтральные кнопки меню.
- `restart_board_reset_wood.wav` — рестарт/пересборка уровня.

## 05_ambient

- `ambient_gentle_distant_water.wav` — очень тихий необязательный фон. Держать примерно на 15–20 dB тише игровых звуков и дать отдельный переключатель Ambient.

## 06_optional_timer

- `last_seconds_antique_clock.wav` — опционально только на последние 10 секунд. Не включать на протяжении всего уровня: постоянное тиканье нарушит спокойный характер игры.

## Что намеренно не озвучивать

- Hover: частый звук быстро утомит, визуального подъёма фигуры достаточно.
- Каждый тик таймера: достаточно визуального счётчика и опционального предупреждения в финале.
- Частицы: они сопровождают удаление и не требуют отдельного эффекта.

Все файлы оставлены в исходном WAV-качестве; перед веб-интеграцией стоит подготовить оптимизированные версии и выровнять perceived loudness.
