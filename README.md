# Anti-Tetris

Клиентская браузерная головоломка: игрок разбирает готовый стакан, удаляя только те тетрамино, у которых свободен вертикальный путь вверх.

## Запуск

```bash
npm install
npm run dev
```

Проверки:

```bash
npm test
npm run build
```

## Архитектура

```text
src/
├── config/levels/     независимые конфиги уровней
├── game/              чистая логика, генератор и GameStore
├── renderer/          PixiJS v8 / WebGL сцена
├── audio/             Web Audio feedback
├── events/            событийная связь слоёв
├── storage/           sessionStorage и localStorage
└── types/             общие игровые контракты
```

`src/game` не импортирует PixiJS. Тестовый уровень находится в `src/config/levels/test-01.ts`: состав фигур, заполнение, время, штраф и параметры генерации меняются без правок игрового движка.

Генератор размещает фигуры в порядке, обратном гарантированному порядку разбора, а затем независимо проверяет результат валидатором. Для `test-01` создаются ровно 25 тетрамино / 100 занятых клеток с максимально равномерным распределением всех семи типов.
