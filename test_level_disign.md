# Anti-Tetris — Test Level Design

## 1. Назначение

Тестовый набор уровней используется для разработки и проверки базовой игровой механики Anti-Tetris.

На текущем этапе предусмотрен один тестовый уровень.

Уровень должен позволять проверить:

* генерацию игрового стакана;
* использование всех стандартных типов тетримино;
* различные варианты расположения и ориентации фигур;
* определение доступных и заблокированных фигур;
* удаление доступной фигуры по клику;
* обработку клика по заблокированной фигуре;
* последовательный разбор стакана;
* определение момента полного прохождения уровня.

---

# 2. Test Level 01

## 2.1. Игровое поле

Размер стакана:

```text
Width:  10 cells
Height: 20 cells
Total:  200 cells
```

Начальное заполнение:

```text
50%
```

Таким образом, генератор должен стремиться заполнить:

```text
100 cells
```

Каждая фигура тетримино состоит из четырёх клеток, поэтому целевое количество фигур:

```text
25 tetrominoes
```

---

## 2.2. Используемые фигуры

В уровне используются все семь стандартных типов тетримино:

```text
I
J
L
O
S
T
Z
```

Все типы фигур имеют одинаковый вес при процедурной генерации.

```text
I: 1/7
J: 1/7
L: 1/7
O: 1/7
S: 1/7
T: 1/7
Z: 1/7
```

То есть вероятность выбора каждого типа фигуры при генерации одинакова.

Строго одинаковое количество фигур каждого типа не требуется, поскольку уровень содержит 25 фигур, а это число не делится на 7 без остатка.

Генератор должен обеспечивать максимально равномерное распределение типов фигур и избегать ситуаций, когда один тип значительно преобладает над остальными.

---

## 2.3. Ориентация фигур

Фигуры могут использовать все допустимые для своего типа варианты ориентации.

Допускаются:

* повороты;
* зеркальные варианты, если они предусмотрены моделью фигуры;
* различные позиции внутри стакана.

Выбор ориентации при генерации должен быть случайным.

Генератор не должен отдавать предпочтение какой-либо конкретной ориентации.

---

## 2.4. Генерация стакана

Стакан генерируется процедурно перед началом уровня.

Исходные параметры:

```ts
const TEST_LEVEL = {
  id: "test-01",

  board: {
    width: 10,
    height: 20,
  },

  fill: 0.5,

  tetrominoTypes: [
    "I",
    "J",
    "L",
    "O",
    "S",
    "T",
    "Z",
  ],

  tetrominoWeights: {
    I: 1,
    J: 1,
    L: 1,
    O: 1,
    S: 1,
    T: 1,
    Z: 1,
  },
};
```

При одинаковом значении `weight` все типы имеют одинаковый приоритет при генерации.

---

## 2.5. Требования к расположению фигур

Каждая фигура должна:

* полностью находиться внутри стакана;
* занимать ровно четыре клетки;
* не пересекаться с другими фигурами;
* сохранять корректную форму тетримино.

Все занятые клетки должны принадлежать конкретной фигуре.

Стакан не должен содержать одиночных клеток, не связанных с тетримино.

---

## 2.6. Разбираемость уровня

Сгенерированный стакан должен быть полностью разбираемым.

Должна существовать последовательность действий:

```text
Initial State
    ↓
Remove Tetromino
    ↓
Remove Tetromino
    ↓
...
    ↓
Empty Board
```

при которой пользователь может удалить все фигуры согласно базовым правилам Anti-Tetris.

Генератор не должен создавать конфигурацию, в которой оставшиеся фигуры невозможно удалить.

После генерации уровень должен проходить автоматическую проверку на разбираемость.

Если конфигурация не проходит проверку, она отбрасывается и генерируется заново.

---

## 2.7. Доступность фигуры

Фигура считается доступной для удаления, если непосредственно над каждой занимаемой ею клеткой отсутствуют клетки других фигур.

Другими словами, фигура должна иметь свободный вертикальный путь вверх.

Схематично:

```text
    free
    free
    free
    ↑
  █ █ █
    █
```

Фигура может быть удалена.

Если хотя бы над одной из клеток фигуры находится клетка другой фигуры:

```text
      X
      █
      ↓
  █ █ █
    █
```

фигура считается заблокированной.

---

## 2.8. Прохождение уровня

Цель уровня:

> полностью разобрать стакан.

Уровень считается завершённым, когда на игровом поле не осталось ни одной фигуры.

```ts
remainingTetrominoes === 0
```

После удаления последней фигуры игра переходит в состояние:

```text
LEVEL_COMPLETED
```

# 4. Критерии корректной генерации

Генерация тестового уровня считается успешной, если одновременно выполняются следующие условия:

1. Размер стакана составляет `10 × 20`.
2. В стакане находится `25` корректных тетримино.
3. Занято ровно `100` клеток.
4. Используются все семь типов тетримино.
5. Типы фигур распределены максимально равномерно.
6. Фигуры не пересекаются.
7. Все фигуры находятся внутри границ стакана.
8. Каждая занятая клетка принадлежит ровно одной фигуре.
9. В начальном состоянии существует хотя бы одна доступная для удаления фигура.
10. Существует последовательность корректных удалений, позволяющая полностью разобрать стакан.
